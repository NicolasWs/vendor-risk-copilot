# Vendor & Risk Decisioning Copilot

**A governed AI agent that recommends, explains, and audits broker /
data-vendor selection decisions for capital-markets trading desks.**

Built by Nicolas Wajs — Product Manager with 15+ years in financial
markets, trading-tech, and data/AI platforms (Finastra, Opensee,
Natixis). This project reproduces, on fully synthetic data, the shape
of a real broker & data-provider selection engagement delivered for a
French asset manager in 2026.

## Why this project exists

Trading-ops and compliance committees today choose and re-approve
brokers and market-data vendors largely on spreadsheets and tribal
knowledge. Banks (per Dataiku/Snowflake's 2026 FSI guidance) are moving
this decision into **governed AI agents**: a model scores the vendor,
an agent explains *why* in plain English, and every decision is logged
for audit — no black box, no un-reviewable autonomy.

This repo is a compact, runnable demonstration of that pattern, built
the way a PM should: a one-page PRD first, then the smallest pipeline
that proves the point, then an explainability layer a non-technical
committee can actually read.

## What it does

1. **`src/pipeline/generate_data.py`** — synthesizes 1,200 realistic
   vendor/mandate evaluations (cost, latency, fill rate, data quality,
   compliance flags, SLA breaches) with a correlated latent "vendor
   quality" factor, so the signal is learnable but noisy — like real
   vendor data.
2. **`src/pipeline/train_model.py`** — a scikit-learn pipeline
   (StandardScaler + OneHotEncoder + RandomForest) mirroring a Dataiku
   DSS "Quick Prototypes" flow: split → prepare → train → evaluate →
   score. Outputs validation metrics, feature importances, and a fully
   scored dataset.
3. **`src/agent/memo_agent.py`** — the "last mile" most ML projects
   skip. Converts model output into a committee-readable recommendation
   memo per vendor/mandate: APPROVE / DECLINE-ESCALATE, confidence,
   top decision drivers, explicit risk flags, and an append-only audit
   log (`data/agent_audit_log.jsonl`) of every input/output pair —
   the governance pattern enterprise AI buyers are asking for in 2026.
4. **`dataiku/`** — equivalent flow built in Dataiku DSS (Free Edition),
   screenshots + exported flow, for readers who want to see the no-code
   version of the same pipeline.

## Results (this run)

- 1,200 synthetic rows, 45% historical approval rate
- RandomForest: **87.9% accuracy, 0.965 AUC** on held-out test set
- Top approval drivers (global feature importance): compliance flags
  (31%), data quality score (16%), fill rate (11%), cost (11%)
- Sample memo (see `data/sample_memos.json` for all 20):

  > Recommendation: DECLINE / ESCALATE (96% model confidence) for
  > Baskerville Markets on Derivatives mandates, APAC region. Key
  > drivers: compliance_flags_12m = 2; data_quality_score = 65.7;
  > fill_rate = 0.89. Risk flags: SLA breach rate 9.5% above 8%
  > threshold. This assessment is model-generated from historical
  > vendor performance data and should be reviewed by the trading-ops
  > committee before final sign-off.

## Quickstart

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python src/pipeline/generate_data.py   # -> data/vendor_mandates.csv
python src/pipeline/train_model.py     # -> data/scored_mandates.csv, metrics, feature importances
python src/agent/memo_agent.py         # -> data/sample_memos.json, audit log
```
